# Rock Paper Scissors

A simple Rock Paper Scissors game playable in the browser.

## How to play

Click on Rock, Paper or Scissors to play a round against the computer. First to 5 points wins. Use the Reset button to restart the game.

## Built with

- HTML
- CSS
- JavaScript
